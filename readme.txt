Obatala is a WordPress plugin that extends Tainacan with features for managing curatorial workflows.

== Description ==

With Obatala, museums can manage the entire lifecycle of their exhibitions and collections — from planning and organization to execution and result analysis. The plugin streamlines detailed cataloging of artworks, exhibition setup, and collaboration among curators, artists, and other cultural professionals.

Obatala also provides tools to support audience engagement initiatives in cultural institutions. Its integration with Tainacan supports metadata-rich workflows and centralized information management.

Development repository: https://github.com/Nocs-lab/Obatala


= Features =

* Process and Step Management: Create and edit curatorial processes with multiple customizable steps.

* Dynamic Metadata: Add and configure custom metadata fields for each step of the process.

* Sector Management: Group users into sectors with specific permissions and assign sectors to process steps.

* Process Interaction: Users can add comments and change the status of process steps.

* Notifications: Send email and admin interface notifications when the process status changes.

* Tainacan Integration: Attach Tainacan items and collections to processes, with access to item history tracking.


== Installation ==

Upload the files to the plugins directory and activate it. You can also install and activate directly from the admin panel.

If you have Imagick installed on your server, Obatala will be able to automatically generate a thumbnail from your PDF files. This is desired but not required.
